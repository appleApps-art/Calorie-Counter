## Наступні виправлення

- Круглі header-кнопки: ширина і висота використовують однаковий масштаб ширини, а не різні масштаби ширини/висоти.
- Після стану voice confirmation відновлюється tintColor мікрофона та imageView; локальна іконка зберігає явний колір.
- Видалення анімує лише видалені блоки й позиції сусідніх рядків протягом 0.26 s; Reduce Motion вимикає перехід. Повторне створення всього списку прибрано.
- У worker оновлено інструкцію збереження запитаної назви без самовільних уточнень. Поточний каталог вже дає точному збігу вищий score; це перевірено для apple, Яблуко й явно запитаного apple with skin. У chat назву генерує модель — тест інструкції не є live-перевіркою якості моделі.

75/75 Node-тестів пройшли. Серверна зміна підготовлена локально; її не опубліковано у Cloudflare. Клієнтські правки потребують нової iOS-збірки.
