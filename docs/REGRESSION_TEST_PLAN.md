# Bity — план регресії

Документ для ручного тесту всієї апки. Копіюй у Google Docs як є: колонка **Статус** лишається порожня, туди ставиш `OK` / `FAIL` / `SKIP` / `BLOCKED`.

У Docs після вставки: **Insert → Table of contents** по заголовках секцій.

---

## Як користуватись

| Поле | Що писати |
|---|---|
| **Статус** | `OK` — пройшло · `FAIL` — баг · `SKIP` — свідомо пропущено · `BLOCKED` — неможливо через інший баг |
| **Нотатки** | білд, девайс, скрін/відео, номер бага |
| **Збіл** | iOS 17+ · Light і Dark · EN і UK · iPhone (мінімум SE і Pro Max) · за можливості iPad |

**Правила**

1. Спочатку **Smoke** (30–40 хв). Якщо fail — не йти в глибокі секції того ж флоу.
2. Повний прогін: усі секції A–Z і AA–AL. Це і є повний людський пакет.
3. Кейси з поміткою **[очікувано немає]** — це не баг, якщо екрана/кнопки немає. Баг лише якщо поведінка інша, ніж у колонці «Очікувано».
4. Quick Log з Home завжди кладе їжу в **Snacks** на **сьогодні** (іншої дати в Home зараз немає).
5. Мережа: частина флоу (пошук, баркод, фото, голос-аналіз, AI-чат) потребує інтернету.
6. Секції **X / Y / Z** — живі фрази. Копіюй текст з колонки «Напиши в чат» як є. Відповідь AI не дослівно: важливі картка, алерт і щоденник.

**Легенда ID:** `A01` = секція + номер. Не перенумеровуй — так зручніше лінкувати баги.

# X. AI-чат — живі розмови (копіюй фразу як є)

Відповідь моделі **не фіксована**. Перевіряй не текст слово-в-слово, а **дію в UI + щоденник**.

Що апка вміє з чату (tool calls):

| Дія AI | Що має зʼявитись | Чи одразу в щоденник |
|---|---|---|
| Запис їжі (`propose_food_log`) | Картка logged meal + рядок на Home | Так, одразу |
| Заміна продукту (`propose_food_replace`) | Картка logged meal, старий рядок змінений | Так |
| Свап (`propose_food_swap`) | Картка swap (оригінал → альтернатива) | Ні, лише після **Apply** |
| Ідеї страв (`propose_meal_suggestions`) | 1+ recipe-карток | Ні, лише після **Log** на картці |
| Вода (`propose_water_log`) | Алерт «Записати N мл води?» | Ні, лише після **Confirm** |
| Рецепт зберегти | Status Saved | У каталог (таб Recipes зараз placeholder) |
| Preference (алергія/дієта) | Status Saved | Наступні поради мають це враховувати |

Чіпи шлють у чат **саму назву чіпа** як повідомлення: EN `Nutrition Q&A` / `Meal Suggestions` / `Food Swaps`. UK: `Питання про харчування` / `Ідеї страв` / `Заміни їжі`.

Історія в запит — останні **20** повідомлень. Памʼять «той самий обід» працює лише якщо той обід був у цій історії.

Перед блоком X: порожній день або свідомо підготовлений щоденник (вказано в кроках). Тестити **і EN, і UK** окремими прогонами.
